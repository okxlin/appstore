# Immich Kiosk

## About

Immich Kiosk displays photos and videos from Immich as a configurable slideshow for browsers, televisions, and digital frames. The project is not affiliated with Immich.

## Configuration

- Set `Immich URL` to an Immich endpoint reachable from the Kiosk container.
- Use a dedicated Immich API key for the Kiosk.
- Optionally provide comma-separated album IDs to limit the slideshow.
- Confirm Immich compatibility before upgrading the Kiosk image.
