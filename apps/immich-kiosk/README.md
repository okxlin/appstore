# Immich Kiosk

## 产品介绍

Immich Kiosk 将 Immich 中的照片和视频以可配置的轮播方式展示在浏览器、电视和数字相框上。本项目与 Immich 官方无隶属关系。

## 主要功能

- 从 Immich 获取照片和视频并自动轮播。
- 可按相册筛选资产，并控制轮播时长、布局和时钟显示。
- 支持反向代理和独立的 Immich API key。

## 访问说明

- `Immich URL` 应填写 Kiosk 容器可访问的 Immich 服务地址。
- `Immich API 密钥` 应使用仅用于 Kiosk 的 Immich API key。
- 可使用逗号分隔的相册 ID 限制展示范围；留空时按 Immich Kiosk 的默认资产筛选规则运行。
- 升级前应确认新版本与当前 Immich 版本兼容。

## Introduction

Immich Kiosk displays photos and videos from Immich as a configurable slideshow for browsers, televisions, and digital frames. The project is not affiliated with Immich.

## Features

- Fetch and rotate photos and videos from Immich.
- Filter assets by album and configure duration, layout, and clock display.
- Supports reverse proxies and a dedicated Immich API key.
