# 思源笔记 SiYuan

## 产品介绍
一款隐私优先的个人知识管理系统。

## 主要功能
- 通过 Web 界面创建和整理个人知识笔记。
- 在 1Panel 中管理访问端口、锁屏密码和持久化数据目录。

## 访问说明
- 本应用使用 Docker Compose 在 1Panel 中部署。
- 应用分类：工具。
- 支持架构：amd64。
- 可选版本：固定版本和 `latest`。
- 安装后按应用表单中的端口访问 Web UI，并输入安装时设置的访问认证码。

## 端口
| 变量 | 说明 | 默认值 | 必填 |
| --- | --- | --- | --- |
| PANEL_APP_PORT_HTTP | 端口 | 40138 | 是 |
| SIYUAN_ACCESS_AUTH_CODE | 锁屏密码 | 随机生成 | 是 |

## 数据持久化
| 变量 | 说明 | 默认值 | 必填 |
| --- | --- | --- | --- |
| DATA_PATH | 数据文件夹路径 | ./data | 是 |

升级或迁移前，请在 1Panel 中备份上述数据目录。

## 使用说明
- 首次访问时输入安装表单设置的访问认证码。升级时保留现有数据目录和认证码。
