# SiYuan

## Introduction
SiYuan is a privacy-first personal knowledge management system.

## Features
- Create and organize personal knowledge notes through a web interface.
- Manage the access port, lock screen password, and persistent data directory in 1Panel.

## Usage
- The app is deployed with Docker Compose in 1Panel and supports amd64.
- Choose a fixed version or `latest` in the app store.
- Open the Web UI at the configured port and enter the access code set during installation.
- `DATA_PATH` stores the SiYuan workspace. Back it up before upgrades or migration, and keep the configured data path and access code when upgrading.
